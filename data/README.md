# Data

The analysis uses two files from the Kaggle dataset
[US 2023 Civil Flights, Delays, Meteo and Aircrafts](https://www.kaggle.com/datasets/bordanova/2023-us-civil-flights-delay-meteo-and-aircraft):

| File | Content |
| --- | --- |
| `US_flights_2023.csv` | all US civil flights of 2023 (about 6.7 million rows, 1.15 GB) |
| `weather_meteo_by_airport.csv` | daily weather for each airport in 2023 |

The files are not included in the repository because of their size. Download them from Kaggle and
place them in this folder, keeping the original names.
